# Sistema de reservas de citas médicas

Trabajo del Grupo 3 de Ingeniería de Software — Tema 6: Proceso Unificado RUP y UML.

El sistema permite registrar pacientes, reservar y cancelar citas médicas en línea y enviar confirmaciones por correo. Quedan fuera del alcance los pagos en línea, la historia clínica y la telemedicina.
